# 0.1.18 工程页面精简

本片只落实用户明确的四项：减少非必要文字、常见信息用toast、图标/问号tip、打开Creator不再二次确认。以原v148已核页面的 hover/focus tip、操作反馈和工程卡为参考。原文件 `web/src/app.ts` 1376–1384、2212、2307–2319 使用文本提示、鼠标与键盘聚焦；继续使用已批准的 Vue / Element Plus，不引入项目或依赖。

## 保留的交互与状态边界

- 主按钮由真实状态选择原 `/start` 或 `/focus`，点击即批准这一项和冻结目标，不发布确认框或临时准备状态；不走setup、不安装Bridge、不配置Codex。
- 等待中保留按钮loading/禁用、同页共享通道和防重复。收到回执但传输清理未结束，不提前提示成功，也不开始结果读取；清理失败保持锁和简短错误。
- 状态未知不当成stopped，失败/取消/UNKNOWN不自动重发。必须取得结果之后的新有效状态读取才能解除原屏障；旧读取不能解锁。更换来源、工程元数据、离页、A→B→A及晚回执保护不撤销。
- toast只陈述“收到回执”，不宣称ready、窗口出现或进程退出。旧回执在重挂载后不重播；Dashboard等信息每个连接只提示一次，不每轮轮询刷屏。
- 仍可从既有日志查询/调用记录入口读取后台记录。重要失败保留短提示和可键盘访问的详情tip，不增加新的操作记录弹窗/页面/导航重排。前端内存回执仍用于安全判定，刷新页面不会证明原动作未执行。
- 停止/重启/目录/移除维持原确认；停止不能保证拦截未保存场景，stopped不证明OS进程退出。安装接入维持原五项主动选择和完整setup确认、任务进度/暂停/UNKNOWN；完成后不铺满主界面。关窗后若任务仍在等待、暂停、UNKNOWN或完成回执清理中，原任务ID、精确路径和完整诊断仍可由状态问号读取；不需要新增历史入口。
- 主导航原分组/顺序/入口保留，仅去开发/迁移说明。帮助、关于、版本入口保留；完整迁移差距留文档，不伪称已完成。

最终测试/构建/静态清单以 `evidence/compact-ui-018.json` 和交付manifest为准。DOM回归使用真实Element Plus组件和fake provider，覆盖单击、双击、Loading、无额外弹窗、确认边界、未知结果、来源切换、旧回执和tooltip转义/键盘操作。

当前工具目录未提供dot cloud browser入口；唯一CUA明确面向用户电脑，不属于本worker操作范围。没有重试此前被拒的exec Chromium，也没有用设计图冒充截图。因此本片不声称视觉像素、窄屏、实际系统窗口或Windows同源行为已验。部署消费者应在真实页面核验这些项。
