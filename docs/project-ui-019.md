## 后台刷新与状态保持

原实时机制按3秒串行读取，没有整页reload或导航循环。但每次projectLoading会使连接按钮转圈、动作禁用并插入通用提示，引起刷新感。现在区分后台读取展示：初次/手动连接仍有等待；已连接的入口重读和live轮询不显示连接spinner，也不插入“正在读取”通用tip。安全projectLoading、单飞、动作在途禁用和错误屏障不放宽。需要核对的持久错误仍展示。

语义相同的工程/状态/Dashboard/warnings复用原数组；真实新快照的revision/时间仍更新。卡片按ID保留，输入、展开偏好与日志滚动不是刷新重建对象；真实状态变化仍必须更新。隐藏/离页关闭与取消、source变动和失败处理继续保持原规则。后台请求失败不显示旧资料为新成功，异常清理仍按原失败策略。
