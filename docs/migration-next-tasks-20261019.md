## 第3项能不能只用任务fixture避开P1060

登记、搜索、折叠可以，已实测。当前UI状态路径是全局`GET /api/status`，宿主遍历所有登记并调用`creator.projectInfo`；选中fixture不改变请求作用域，因此会涉及P1060。没有确认可由现有UI直接使用的单工程状态路径。本轮没有发全局status，也没有通过移除P1060登记、改宿主或启动Creator凑验收。

因此第3项只保留一个明确缺口：在允许状态探测的实机窗口完成状态→UI对应。若P1060持续暂停，当前已批准路径不能完整验证该部分；保持待验即可，不为比例新造接口。
