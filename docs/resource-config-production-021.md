# 1.3.171 资源规范正式入口接线

## 范围

- `/resources?project=<登记 ID>&step=1` 复用 `AiResourceReadView` 的已保存规范摘要、参考预览和 `AiResourceConfigDialog`，不另建配置草稿或保存协议。
- `/ai-icons?project=<登记 ID>` 使用 `registered-project` 的同一工程选择和正常工程入口读取机制。AI 页面选择器写入路由，支持前进 / 后退；两页的互链携带当前工程 ID。
- 嵌入资源第 1 步时不重复挂载登记读取生命周期，不显示第二个工程选择器。
- 新建缺失配置、显式 v1 → v2 迁移、编辑 v2 都进入现有共用表单。保存 provider 缺失时仍只能预览，不把有 UI 当作已有写权限。
- 现有参考图片预览为显式操作；配置弹窗内复用现有本地解码 / Canvas 预览及独立上传确认。

## 状态与权限

- 读取、编辑草稿、上传回执、配置保存、生成、视觉批准、导入与运行验收分别留证。
- 读取或编辑不会自动保存。每次配置写入仍冻结原工程 ID、路径、来源、配置 hash 和本次差异；字段变更撤销确认。
- 参考上传单独确认。上传回执只加入同一有效工程的编辑草稿，不能直接改变已保存摘要；仍须另行保存规范。
- 保存成功事件仅在编辑器仍处于当前工程、上下文有效且保存回执已核验时刷新当前规范。不会用 A 的晚到结果刷新 B。
- 切换工程、同 ID 路径更换、来源更换或离开页面沿用既有读取取消与编辑器失效逻辑。变更后的登记路径必须显式重新选择，不能自动续用旧写权限。
- 未知结果继续保留已有 UNKNOWN fence，返回页面、关闭弹窗、重新选择文件或查看保留草稿都不授予重试权限。
- Owner 资产保护、原文件 hash 并发保护、上传 / 保存互斥以及参考不作为模型图像输入的边界保持不变。

## 未接范围

最终整合中第3–4步复用原任务读取组件，手动读取jobs/status/candidate；第2/5/6步仍标注库存、导入 / UUID / 绑定和运行证据缺口，任务候选读取不代表批准或导入。此改动没有加入生成、批准、导入、导出或运行接口，也没有用示例数据填补生产页面。

provider 正常 workspace 注册由主入口接线负责；本文页面改动不改变运行服务、认证、后端合同或部署。
