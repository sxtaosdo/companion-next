# 人工生成文件回收

## 可用路径

1. 在资源规划中建立需求、编入批次、选择本地 ComfyUI 或 Codex 原生。
2. 在第 3 步「回收生成结果」选择一个已编批、非 Owner 保护母图需求。
3. 选择自己保管的 PNG 文件。文件不会上传；应用读取一次字节，计算 SHA-256，提取有限 PNG 结构元数据，然后释放字节引用。
4. 查看默认尺寸匹配或不符的记录、原来源与规范绑定，导出本地回收清单，连同原图交给后续审阅端。

不需要 Windows 服务、账号、SDK 或外部生成 API。真实项目 provider 尚未接通时，示例模式仍显著标明是示例项目；文件测量来自选择的实际字节，但不能因此视为真实项目产物。

## 合同与可信边界

`src/domain/generation-receipt.ts`：

- `createReceiptContext(plan, requirementId)` 使用既有严格计划合同，冻结项目 / 模式、计划 ID、规范快照、需求、批次、来源；拒未选来源、未编批、Owner 保护与伪造执行状态。
- `inspectGenerationFile(context, { name, bytes })` 限 16 MiB、8192² 像素、8192 块；校验 PNG 签名、核心块布局、CRC、位深、颜色类型、zlib 头，拒 APNG、截断、尾随数据和不支持的关键块。文件名为无路径文本。实测哈希绑定完整所选字节，不是 URL 或表单里填写的哈希。
- 有限结构检查不是完整 PNG 解码：没有解压、像素颜色 / alpha / 边缘检测。`alphaDeclared` 只是 PNG 声明有 alpha 通道；`hasTransparencyChunk` 只是结构声明。二者都不等于实际透明像素或透明质量通过。所有回执 `status: needs-review`，包括尺寸匹配时。
- `sourceDeclaration: user-declared`、`sourceVerification: not-verified`：选择 Codex / ComfyUI 只是声明，不证明文件确实由该服务生成。不声称已接通任务状态或执行日志。
- `fullDecode`、`pixelTransparency`、`visualReview`、`ownerApproval`、`runtime` 都为 `not-checked`；`savedToProject`、`imported`、`bound` 为 false。计划的执行计数不变。
- 内部冻结对象与本会话标记防止误把 JSON 克隆当作实测证据。该标记不是数字签名或跨进程证明，恶意控制网页脚本不在它的保证范围。

回收清单 `companion-generation-receipts` 与计划 / 出站交接 JSON 分开。只能导出实际读取产生的原记录，无收据导入入口，也不接受空列表当结果。它包含元数据和原规范快照，不包含原图或凭据。导出不代表清单或原图已保存到项目。

## 生命周期与限制

- 每项目 / 模式 32 份记录，完整清单规范化输出不超过 512 KiB；存入前校验预算，失败保留原记录。
- 同上下文 + SHA-256 重复拒绝。换来源可以重新选择文件建立新的自报记录，但不重写旧记录。
- 旧记录与其原来源 / 规范 / 需求保持绑定；当前计划不同则显示历史绑定，不据 ID 相同隐式重绑。
- 单次读取；取消、项目 / 模式 / 来源 / 规范 / 计划 / 路由改变、离页均使旧读取失效，包括 A→B→A。操作结束前再检查绑定。
- 只收默认母图；实际尺寸不符留下待处理信息，不进行图片缩放、裁切或派生。当前不提供图片预览，因现有同源托管 CSP 不允许 blob 图片；不放宽 CSP。
- 页面内存保存元数据，刷新丢失；原文件由用户保管，导出的清单只是交接记录，不能恢复成已核验产物。重新登记需重新选取实际文件。

## 必要下一步与精确缺口

1. 自动来源任务状态 / 回收：ComfyUI 缺已登记实际工作流版本、输入 / 输出映射、任务 ID、状态 / 取消 / 文件读取合同；Codex 原生缺网页可调用的会话生成与产物回收接口证据。本片不猜造 API。
2. 完整技术与视觉验收：缺经过实际浏览器验证的图像解码 / alpha 边缘检查链路，以及 Owner 对目标规范与图的审批证据；结构检查不能替代。
3. 工程交付：缺真实项目资源 / 规范读写、批准文件与目标路径的绑定、原子保存回执、Cocos UUID / Prefab 引用 / 运行证据。Picker 图片素材独立保存合同不等于这些生成资源已写项目。
4. 浏览器验收：文件选择 / 下载、真实 WebCrypto、原 CSP 下页面呈现仍需受支持浏览器验证；本片只做离线合同与 DOM 回归，不重试已拒绝 Chromium IPC 路径。

没有修改 Picker handler、桥接源、旧 Windows Companion 或依赖锁文件。
