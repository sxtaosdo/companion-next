## 本地生成文件回收

建立资源计划、编批并选择来源后，在第 3 步为具体需求选择 PNG 母图。每张不超过 16 MiB、8192 × 8192；每项目 / 模式最多 32 份记录。校验文件块、CRC 与尺寸声明，计算整文件 SHA-256；尺寸不符仍保留为待处理记录。没有进行完整图像解码或像素透明质量检查，来源仅为用户声明，所有记录均待审。

记录与原规范、需求、批次及来源快照绑定。切换来源不重标已有记录，读取期间上下文或路由改变会丢弃晚到结果。图片不持久化，仅元数据存在页面内存；刷新前导出清单并保留原图。导出上限 512 KiB，不能把编辑过的清单导入成实测证据，重新核验需选择原图。

此路径不依赖 Windows 服务，不新增 API；自动生成任务、像素 QA、视觉批准、项目保存与 Creator 导入依然独立待接。详见 `docs/generation-receipts.md`。
